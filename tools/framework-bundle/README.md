# Linux framework inputs

`manifest.json` is the reviewed, Linux-only source lock for CppUTest 4.0 and
Unity 2.6.1. The SHA-256 values were calculated from the exact HTTPS release
archives named by the lock. Bootstrap code must reject missing, mismatched,
redirected, or path-escaping inputs before a native process tree is launched.

The lock is an input boundary, not a runtime network exception: CI may populate
the immutable archive cache before the native offline boundary is entered.
